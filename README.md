# SWYNEX-Exploratory-Data-Analysis

1.Import libraries (pandas, numpy, matplotlib, seaborn)
2.Load dataset (pd.read_csv() or pd.read_excel())
3.df.head() → preview first rows
4.df.shape → check dimensions
5.df.info() → data types & nulls
6.df.describe(include='all') → summary statistics
7.Histograms for distributions
8.Count plots for categorical variables
9.Boxplots for spread 
10.Pie charts for proportions
